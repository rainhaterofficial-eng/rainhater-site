# rainhater.com

The website for rainhater. It's a plain static site: just HTML, CSS, a little JavaScript, and images. No build step.

## Files
- `index.html`, `coaching.html`, `merch.html`, `about.html`, `contact.html`: the five pages
- `assets/css/style.css`: all the colors, fonts and layout (colors are at the top)
- `assets/js/main.js`: small extras (fade-ins, the music bar play button)
- `assets/img/`: images (the `.svg` files are placeholders to swap for real photos)
- `assets/audio/latest.mp3`: drop a song here to make the "Now playing" bar play it
- `CONTENT-NEEDED.md`: the list of placeholders still waiting on real content

## Preview on your computer
Open `index.html` in a browser, or run `python3 -m http.server 8080` in this folder and visit http://localhost:8080.
